# 翻译审校网页工具

翻译与审校统一使用本地网页工作区，不要手工编辑翻译或审校 JSON。

## 启动

先安装 `uv`，然后进入 `_localization\tools` 启动：

```powershell
cd .\_localization\tools
uv sync --locked --dev
uv run --locked aetext review
```

也可以从仓库根目录启动：

```powershell
uv run --project .\_localization\tools --locked aetext review
```

首次运行会准备 Python 环境。使用期间保持终端运行；浏览器未自动打开时，打开 `AeText review:` 后显示的
本地网址。

**界面语言**控制网页显示语言，**译文语言**选择当前编辑的译文。

## 扫描

- 新检出仓库时，选择 **扫描 > 扫描所有插件源码**。
- 只处理一个效果时，选中它并选择 **扫描 > 扫描当前插件源码**。
- 页面提示数据过期时重新扫描。

## 翻译与审校

1. 选择插件和译文语言。
2. 在 **译文** 中填写翻译；保留原文时启用 **使用原文**。
3. 下拉菜单文字通过 **编辑下拉项…** 修改。
4. 确认翻译后，将 **状态** 设为 **已校对**。

## 保存

`*` 表示有未保存的修改。使用 **保存当前插件** 或 **保存全部改动** 完成保存。

## 检查发布审校

保存后，选择效果或 Language Settings，并使用 **扫描 > 检查当前插件发布审校**。

## 停止或重新打开

在终端按 `Ctrl+C` 停止服务；再次使用时重新运行启动命令。
