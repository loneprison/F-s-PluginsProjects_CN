# 翻訳レビュー Web ツール

翻訳とレビューにはローカル Web ワークスペースを使用し、翻訳またはレビュー用 JSON を手作業で
編集しないでください。

## 起動

`uv` をインストールし、`_localization\tools` から起動します。

```powershell
cd .\_localization\tools
uv sync --locked --dev
uv run --locked aetext review
```

リポジトリルートから起動する場合：

```powershell
uv run --project .\_localization\tools --locked aetext review
```

初回は Python 環境が準備されます。使用中はターミナルを動かしたままにしてください。ブラウザーが
開かない場合は、`AeText review:` の後に表示されるローカル URL を開きます。

**表示言語** は Web UI、**翻訳言語** は現在編集する翻訳を選びます。

## スキャン

- 新しい checkout では **スキャン > すべてのプラグインソースをスキャン** を選びます。
- 1 つだけ処理する場合は、選択して **スキャン > 現在のプラグインソースをスキャン** を選びます。
- データが古いと表示された場合は再スキャンします。

## 翻訳とレビュー

1. プラグインと翻訳言語を選びます。
2. **翻訳** に入力します。原文を残す場合は **原文を使用** を選びます。
3. ドロップダウンの文字は **ポップアップ項目を編集…** から変更します。
4. 翻訳を確認したら、**状態** を **レビュー済み** にします。

## 保存

`*` は未保存の変更を示します。**現在のプラグインを保存** または **すべての変更を保存** を使います。

## 公開レビューの確認

保存後、エフェクトまたは Language Settings を選んで **スキャン > 現在のプラグインの公開レビューを確認** を選びます。

## 終了または再表示

ターミナルで `Ctrl+C` を押して停止します。再度使う場合は起動コマンドを実行します。
